O que essa frase está escondendo

Ela apareceu ao mudar a situação de um lead. Não é diagnóstico: é a frase que o painel diz quando qualquer coisa dá errado — e hoje ele não consegue distinguir cinco problemas muito diferentes, dois dos quais não têm nada a ver com rede.

00

A frase mente, e o código explica por quê

Este é o pedaço que roda quando você toca na situação. O .catch da última linha é quem imprime a frase.

app.zaq-ia.com diz

OK
O .catch de um fetch dispara em duas situações completamente diferentes: a rede caiu ou o servidor respondeu uma coisa que não é JSON. O código não olha qual das duas foi — só imprime "Falha de rede".

O único lugar que acertou já está no código, e é de uma linha: return r.ok ? r.json() : null; — a faixa que avisa que saiu versão nova (web/portal.py). Não é um recurso a inventar; é um que existe em 1 de 120 lugares.
02

A solução: um caminho só pra falar com o servidor

Em vez de consertar 119 lugares um a um, um único zapFetch por onde todos passam. Quem chama não muda quase nada; o que muda é que existe UM lugar que sabe o que aconteceu.

hoje cada tela adivinha

fetch(url,{…})
  .then(function(r){return r.json();})
  .then(function(d){ … })
  .catch(function(){
    alert('Falha de rede.');
  });
Trava a tela com um alert, some sem deixar rastro, e não oferece o que fazer.

proposta um lugar só decide

zapFetch(url,{…})
  .then(function(d){ … })
  // sem catch: o zapFetch já
  // mostrou o aviso certo,
  // com a ação certa
Confere r.ok, lê o corpo uma vez, classifica pelo código HTTP e mostra a mensagem daquele caso.
o que cada caso passa a dizer
📡 Você está sem internet. O fetch nem saiu do navegador. Único caso em que "rede" é a palavra certa.
🔄 Estamos atualizando o Zaq. Tentando de novo… 502/503/504 — a janela do deploy. Tenta sozinho 2 vezes, com 2s e 5s de espera: na maioria das vezes a pessoa nem vê o aviso, o toque só demora um pouco mais.
🔑 Sua sessão expirou. Entrar de novo 401/403 ou a página de login vindo no lugar do JSON. Hoje isso também vira "Falha de rede".
⚠️ Não consegui salvar — o erro ficou registrado. 500. O aviso diz o número do ocorrido, pra você me mandar e eu achar no log em vez de adivinhar.
🧭 Esta aba está desatualizada. Recarregar A resposta veio de uma versão diferente da que esta aba carregou.

Por que não é mais alert: o alerta do navegador para tudo até alguém clicar em OK, não cabe botão de "tentar de novo" e, no celular, cobre a tela inteira. O aviso aparece no canto, some sozinho quando deu certo e fica até você mandar embora quando deu errado.

a proposta
