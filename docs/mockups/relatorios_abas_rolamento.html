3 · a proposta — sinal de rolagem

Um gradiente na borda, só quando tem mais pra ver

Mesmo padrão que app de celular, catálogo de produto e navegador usam pra lista horizontal: uma sombra sutil na borda de quem tem conteúdo escondido, que some sozinha quando chega no fim. CSS + um pedacinho de JS pra saber se chegou na ponta — nenhuma mudança de comportamento, só o aviso que faltava. Escopo só na faixa de abas: a tabela, depois do #571, só raspa por poucos pixels em 1024px — não vale o código extra por enquanto.

● propostomesma simulação (1024px), com o gradiente nas duas pontas
👉 arraste de novo — repara a sombra sumindo na ponta que você já rolou até o fim, e aparecendo na ponta que ainda tem mais.
De propósito, sutil: combina com o visual discreto do app — mas é bem sutil mesmo. Se preferir algo mais chamativo (uma setinha, por exemplo), eu troco antes de fazer — é só dizer.
4 · resumo do que muda no código

Só CSS + um pedacinho de JS, num arquivo só

OndeO quê
web/portal.py (_RELATORIOS, bloco de estilo) Gradiente nas bordas de #rel-abas, escondido por padrão (classes .no-left/.no-right) e mostrado via JS quando há mais conteúdo pra rolar naquela direção.
